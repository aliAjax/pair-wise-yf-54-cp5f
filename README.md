# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化。

## 多平板断网合并
- 每台平板有独立编号（顶栏可切换 / 新增平板），断网期间的签字、环境读数、条件检查、差异处理全部进入本地操作队列。
- 网络恢复后按「记录编号 + 字段版本」合并：`baseVersion >= 当前版本` 干净合并，否则判定为版本冲突。
- 冲突读数保留两版并标明来源平板，界面列出复核原因，保管员确认采用一版后锁定。
- 签字时记录读数快照与未解决差异版本；任一读数 / 条件 / 差异版本变更都会让原签字失效，复核完成前不能推进。
- 同设备对同一字段的多次修改以最新为准（重复处理仍算一项）；同角色同来源签字幂等去重。
- 合并失败保留原操作与重试队列；重试不能覆盖他人已确认的数据，失败项可手动重试。
- 「合并与复核」页签集中展示等待复核项与等待处理项（含复核原因、来源、重试次数）。
